## 关键观察与判定口径

1. **Crystal Audio 专属修复不算 CHS 当前 Bug**：#061～063 针对 RPP crysaudio 的音效命令和播放实现，CHS `src/audio/engine_1.asm` 未使用该引擎。只有用户能在 CHS 复现相同听感问题，才值得用 CHS 本机音频路径检查。
2. **CHS 有意保留的 UX 与 RPP 不同**：#064 的取消治疗后立即退出、删除告别与 CHS QOL-1.1 规定“保留取消后告别”并不一致；只能记为部分相似，不能写为 CHS 漏修。
3. **相同目标不等于相同内部代码**：#065 START 显示/字体时序已由 CHS QOL-1.11～1.16 适配汉化 DFS；#068 版本号复用已由 QOL-1.12 和当前 GameVersionText 实现，均不再重复搬迁。
4. **依赖链整体对待**：#073～076（Bill PC 连续存取）、#078～082 与 #085（分类背包）、#086～090（特殊飞行地点）应作为单独功能项目考虑，不能抽一个看似简单的后续修复直接 patch 到 CHS。
5. **证据级别**：“已实现”须由 CHS 源码/历史支持；“部分实现”指目标仅覆盖部分；“需评估”指新增功能/体验选择；“当前不适用”指专属依赖不存在；“依赖暂缓”指前置提交未实施；“缺号”指无参考提交。**未找到符号不是不存在相似问题的绝对证明。**

## 建议给维护者的优先顺序

- **优先讨论的中等复杂度候选**：#073～076 的 PC 连续存取与界面留存值得作为**一个整体**考虑；#083 START 会话内光标记忆、#084 重复钓鱼、#071 训练师出场文本自动滚动是可选体验改进。
- **较小、可独立决定的视觉项目**：#066 黑夜魔影动画。CHS 当前仍是长闪烁，属于“喜好与可读性”，非已证实故障。
- **已做或需保留差异，不重复套**：#065 START、#068 版本显示；#064 的精灵中心取消后告别文本是 CHS 用户既定取舍；#085 的 USE/TOSS 入口已有，但参考完整的描述/分类系统尚不存在。
- **复杂重构暂缓**：#077 MoveDex、#078～082 分类背包、#086～090 特殊 Fly 扩展与相应 WRAM/VRAM/存档逻辑。参考对这些新增系统的 Bug 修正不可直接成为 CHS 待办。
- **当前不适用**：#061～063 Crystal Audio、#067 MoveDex 退出地图图块；没有证据说明 CHS 具有这些参考系统专属 Bug。
- **下批**：#091～120，仍需对照实际独立提交补丁逐笔核实；本轮不提前归类。
