# 中英文名称设置与英文旧存档兼容规则（需求记录，不在本轮实施）

基线：用户已确认 QOL-1.16 正式提交/推送。当前 Names 选项只切换 `GetMonName` 的中文/英文物种名表；`GetPartyMonName` 等直接复制已有昵称，因此英文旧档的默认物种名称仍可能显示英文。此为当前行为的分析记录，不表示已经修复。

## 未来实施规则

1. **只做显示转换，不批量改写 SRAM 的原始名称**：依据物种 ID 获取对应的中文、英文标准名称；已保存名称与该物种的任何一种默认标准名称完全一致时，显示当前设置选择的标准名称（中文 / 英文）。
2. **真正的自定义昵称原样保留**，不做机器翻译，不因语言切换覆盖；玩家名、劲敌名等也不参与物种名称转换。
3. 进化时的“是否为默认物种名称”判断须与显示使用一致的双语比较策略，避免旧英文默认名称被误判为自定义昵称而阻止进化后更新名称。
4. 旧存档、联机和存档长度/编码保持兼容；新实现不能修改 `NAME_LENGTH` 或 SRAM 结构。注意：第 1 世代未保存独立“曾否自定义昵称”的可靠标志；若玩家主动改名为恰好等于中文或英文标准物种名，将被视为默认名称——这是一项需接受的边界。
5. 中文动态字形（DFS）由现有显示路径加载和同步；不能在屏幕重新绘制后显示失配字形。切换 Chinese/English 时，要确保队伍、PC、摘要/状态与图鉴具有一致语义。

## 本规则的最小验证边界（未来开展时才执行）

- 英文旧存档：默认英文名在 Chinese/English 下分别显示当前语言名称；队伍和 PC 直接相关路径。
- 自定义英文昵称切换语言后不变化。
- 汉化版新获得的默认中文名能双向切换。
- 一只未自定义昵称的英文旧档宝可梦进化后正确更名；不要求全物种、全地图回归。
