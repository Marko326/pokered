# CGB CPU 双倍速验收记录（CPU-1.6）

## 本轮变更

- 在已提交的 `CGB-1.5`（HEAD `6a7ce60d`）上，CGB 野外请求 CPU 双倍速，进入战斗与大木博士开场时请求恢复单倍速，软复位及 Init 归一化到单倍速。
- DMG 模式不执行双倍速切换；不修改已确认正常的原生 CGB 配色、DMG 60 FPS、汉化和存档数据。
- 速度切换的必要执行例程保留于 ROM0；未新增 WRAM、SRAM、HRAM 状态。
- 清理测试后缀 `A`，移除仅用于验收的 START+SELECT / KEY1 临时诊断显示及所有相关代码。

## 用户运行验收

- CGB 野外：在临时诊断页面中直接读出 `CGB KEY1: 2X`，确认野外已进入 CPU 2x。
- DMG：临时诊断页面显示 `DMG: 1X (NO KEY1)`，符合不切换 CPU 的预期。
- 临时诊断界面的乱码经修复后，两种模式截图均清晰可读；诊断代码不随正式版保留。
- 用户已提供野外骑行、队伍和战斗返回等场景的演示，未报告本轮可见异常。

## 尚待单独验证

- 当前截图确认的是野外瞬时 KEY1 状态，未直接读取战斗期间的 KEY1；战斗恢复单倍速需要另行测量才能视为已实测。
- 尚未获得本次正式版红、蓝 MAP，ROM0 实际余量仍以用户本地链接结果为准。
- 本轮补丁只做静态校验；AI 不编译 ROM，也没有执行 Git 提交。
