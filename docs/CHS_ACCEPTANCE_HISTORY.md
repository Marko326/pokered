## MOV-1.7 — B 快走与自行车加速

> 历史来源：`CHS_MOV_1_7_ACCEPTANCE.md`（内容完整保留；标题层级统一）

### 野外移动加速验收记录（MOV-1.7）
#### 功能
- B 键快走：仅在正常步行时启用，每个野外更新帧推进 2 像素，整格仍为 16 像素。
- 自行车：正常骑行每帧推进 4 像素；17 号道路上坡或横向移动保持原来的每帧 1 像素限制。
- 冲浪、跳台、NPC/门口强制走动、模拟输入时不额外加速。
- 每一帧都保留最后一次正常的 `AdvancePlayerSprite`，加速前先检查 `wWalkCounter >= 2`，避免切换按键时计数器下溢。

#### 适配与空间
- 来源：参考工程 QOL 的 `MOV-1.11` 历史功能提交（`afd9afe8`）。
- CHS 特有适配：按实际 `wd730`、`wd736` 和输入常量检查；不移植参考工程的独立 START 菜单改动。
- 修正参考算法中重复调用 `DoBikeSpeedup` 导致一次调用可能推进 2 像素的风险；这里每次额外调用仅推进 1 像素。
- 速度主体在 Bank `$2D` 的 `Player Speed Steps`；ROM0 仅保留 FAR 调用，不新增持久状态或存档变量。
- 移动代码由用户提供的 DMG/CGB 骑行视频验证；AI 未编译 ROM。实际空间以用户新 MAP 为准。

#### 视频验收（已确认的项目）
- [x] DMG / CGB：骑行录像中有正常步行约 1 像素/有效移动帧、快走阶段约 2 像素/有效移动帧；按键状态不可从录像直接读取。
- [x] DMG / CGB：普通道路连续横向骑行约 4 像素/有效移动帧（每格 16 像素对应 4 个有效移动帧）。
- [x] 骑行视频中的左右往返没有观察到明显的地图碰撞错位或画面异常。
- [ ] 17 号道路上坡、横向移动和顺坡移动尚未由本次视频单独验证。
- [ ] 冲浪、跳台、剧情移动、出入地图/战斗和旧存档兼容未由本次视频全面验证。
