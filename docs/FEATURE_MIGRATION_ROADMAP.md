# CGB 项目功能差距与移植路线图

本清单对照当前 CGB-1.17 源码、Red++ 参考项目源码、PureRGB 相关实现和已提供的个人历史 Patch。状态“缺失/未见同等实现”是源码盘点结果，不代表已逐项运行测试。参考项目有数千条历史提交，现有个人提交包约 444 条，不能视为完整历史。

## P2：其他便利功能

- 喷雾到期时询问是否续用。
- 捕获过的野生宝可梦标记。
- 战斗经验条增长动画。
- 连续使用治疗/PP 道具的流程优化。
- 继续游戏/存档页面显示当前位置。
- 飞翔地图快捷定位。
- SELECT 钓鱼（当前 SELECT 自行车候选不包含此功能，需单独评估）。

## 暂缓：复杂系统与存档/战斗架构变化

- 分类背包与容量从 20 扩展到 100 槽。
- 地区形态、性别/闪光身份、繁殖。
- 扩展招式及完整招式身份管理。
- 新属性、物理/特殊分家、MoveDex。
- 新地区、大量地图和复杂剧情。
- 联机对战规则与大型战斗引擎改造。

这些系统跨越数据表、战斗状态、ROM Bank、存档结构或多个菜单。必须先完成依赖图与存档兼容评估，不能按单个历史 Patch 直接复制。

## 工程约束

- 本项目优先保留现有 CGB-1.13 速度和调色板架构。
- 新功能主体优先放 ROMX；Bank 0 仅保留必要入口/高频短路径。
- 不直接复制 Red++ 的整份文件；以当前 CGB 源码为基线做最小差异。
- 每项独立制作测试候选、手机验证后再收口。
- 测试通过前不清理测试标记、不生成正式提交日志。
