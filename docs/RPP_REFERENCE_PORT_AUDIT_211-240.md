# RPP 参考分支移植台账：第 08 批（211～240）

> **CHS 对照基线**：`ROM-1.21.zip` / `CHS_Mod` 已提交 HEAD `70549f631b187d2062a3b952a0d26426804d38b1`。
> **参考来源**：交接资料包 RPP `individual/211～240` 原始提交补丁，共 30 笔，未发现缺号。
> **审查方法**：逐笔核对原始标题、Hash、提交说明和改动文件，并与 CHS 当前 `src/` 代码和既有审查历史对照。结论限于静态分析；**没有执行新 ROM 构建与游戏运行，待核验不等于已复现 Bug**。
> 本轮**只交付文档补丁**，不修改游戏功能、WRAM/SRAM、版本号、音频引擎或 ROM Bank。

## 本批最重要的判断

1. **#213 游戏厅兑换循环**：CHS 兑换/失败/取消后仍退出奖品列表，属于实际 QoL 差异，适合独立评估。
2. **#214～225 地图地名牌是一个新功能链**：以 #214 引入 Crystal 风格地图地名牌为前提，#215 的连续刷新与 START Window 交接、#216 的 90 帧、#217～225 的地图/楼层扩展必须作为整体看待。它们不是 CHS 当前 10 多个地图 Bug，更不代表 CHS 使用 Crystal Audio 音频引擎；这里“Crystal”只是参考的视觉风格。
3. **#221 60 FPS 旋转地板**：CHS 已有 60 FPS，但 spinners.asm 仍逐块执行 CopyVideoData。可能存在节奏不够流畅的相似问题，先用火箭队基地/常青道馆运行确认，再决定是否最小修复。
4. **#219 已实现**：CHS 主菜单与 Options 已共用 `GameVersionText` 显示 `ROM-1.21`，不重复移植。
5. **#228 当前不适用**：参考 Move Deleter 的菜单光标和单技能 `pop bc` 栈问题非常具体，但 CHS 当前缺少对应独立 NPC 脚本，不能认定为 CHS 已有 Bug。
6. **#230～235 地区形态**：成套新增 framework、持久化、图片、图鉴与捕获逻辑，依赖极重。**高复杂度暂缓，不拆分套用。**
7. **#236 基础种族数据压缩**：潜在空间优化，但参考使用 208 只物种与地区形态、导师等扩展结构，与 CHS 原有数据格式不同；不要套整包数据改动。
8. **#237 神奇糖果提示**：CHS RareCandyText 仍有音效后 text_promptbutton，这是一项可实测的轻量 QoL 差异；测试再决定是否减少一次按钮。
9. **#239 不可移植**：RPP 固定 Hard / Set 的死代码对 CHS 并非死代码，不能为了省 50 B 删除 CHS 战斗规则。
10. **#240 TM 机器兼容**：CHS 与 RPP 旧实现存在“根据招式找第一台 TM”的共同算法隐患；当前配置尚未确认重复技能，不能说用户已遇到故障。建议保留为预防性评估，AI Hard 专属去重则不移植。
