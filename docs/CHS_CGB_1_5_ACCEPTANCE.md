# CHS_Mod CGB 原生配色验收记录（CGB-1.5）

## 实际修改

- 基于已提交的 `FPS-1.4` 汉化工程，移植 CGB 原生调色板及 DMG 灰阶映射。
- 按汉化版的 `home2.asm` 初始化顺序安排调色板写入。
- 使用 CGB 背景／精灵颜色映射及精灵属性兼容处理；保留现有 DMG 60 FPS。
- 颜色处理主体放在 ROMX Bank `$3C`，ROM0 只保留必要入口及 VBlank 相关调用。
- **本次没有启用 CGB 双倍 CPU**，没有引入音乐关闭及音量功能。
- 本轮正式清理只将 `CGB-1.5A` 改为 `CGB-1.5`，不改动已测试的配色执行逻辑。

## 验证情况

- **用户实测**：DMG 与 CGB 两种模式显示正常，特别是 CGB 未出现之前的颜色异常；队伍、战斗和战斗结束未发现问题。
- **补丁静态验证**：增量和全量补丁按各自基线做正向及反向应用，核对最终文件内容和权限。
- **尚待验证**：未由 AI 编译 ROM；没有本版新生成的 Red/Blue MAP，ROM0 最终余量、其他剧情场景的颜色仍以用户后续测试为准。

## 后续规划

- 用户在 RPP Mobile 完成本版提交后，CGB CPU 双倍速独立做新一轮测试补丁，避免与已稳定的颜色功能混合。
