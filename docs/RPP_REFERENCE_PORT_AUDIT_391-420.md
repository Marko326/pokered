# RPP 参考分支移植台账：第 14 批（391～420）

> **CHS 基线**：已提交 `ROM-1.21.zip`，`CHS_Mod` HEAD `70549f631b187d2062a3b952a0d26426804d38b1`。
> **参考来源**：RPP 交接包 `individual/391～420`，已逐个读取 **30 笔实际提交 patch**，本批无缺号。
> **边界**：仅静态核对参考补丁、当前 CHS 源码/历史；不编译、不做模拟器实测、不改游戏行为。参考的 Crystal Audio、地区形态和扩展招式 Bug 不等于 CHS 有相同故障。

## 本批关键结论

1. **#417 战斗 PP 道具是最值得独立复现的候选**。CHS 有 Ether/Elixir 与 `wActionResultOrTookBattleTurn` 对应路径，但不能只从控制流判断实际是否发生“成功后重复选择/未消耗回合”。要测成功、取消、无效果及剩余库存四类情况；参考还包含连续升级后的菜单边框与逐字延迟优化，须独立看待。
2. **#406 主菜单/Continue 加载优化仅部分实现**。CHS 的 START 字库、显示修复已有历史验收，但 MainMenu 仍每轮清屏、重载字体；RPP Mateo 开场与 CHS 不同。建议先在 CHS 测量主菜单路径收益，不替换现有汉化缓存流程。
3. **#392～405 是地区形态图库、种族数据、独立图鉴、捕获标记和研究评价的连续链**。CHS 没有该框架，#400、#402、#405 等后续修复是 RPP 增加功能后产生的问题，不得归入现有 CHS Bug。特别不能照抄 SRAM 偏移或物种形态 ID。
4. **#407～408 是 Crystal Audio（Crysaudio）SFX 等待与清理**，CHS 没有该引擎；#409 的 Volt Tackle 也不在 CHS 当前招式表。仅保留独立复现原则，不套专有路径。
5. **#410～416 涉及扩展招式/按物种重解释旧 Move ID**。#413 的 Bite→Bug Bite 和 #414～416 的 Agility→Rock Polish 会改变旧招式语义及中文字样/AI，不按 Bug 修复。
6. **#418～420 属于招式扩容与存档身份表示的底层重构**，涉及 Party、PC、盒子、回忆及存档兼容，属于最高复杂度、目前暂缓。
7. **#391、#392 为用户可选视觉更新**，与已有 CHS 游戏功能不同，不应强制移植。#391 应先独立核查上一批 #390 双针中毒/替身问题，再考虑视觉层。
