### 本次 C 源码状态的技术边界

- **保留用户所选的 C 状态**：此次没有纳入后续独立开发的 `ROM-1.27D` 版“数字＋单位完整右对齐”实验补丁；不能把 D 的效果冒称为本次正式提交内容。
- SAVE / Continue 信息框保留原版横向位置与 **13 格内容宽度**。第一行四个汉字的固定标签占 6 格、两栏最少间隔 1 格，右侧地名最多 6 格；按照完整字符边界安全截断，不拆分 DFS 双字节汉字。
- 新增中文「当前位置」使用 `src/charmap.txt` 现有四字的显式字码，避免不同 charmap 构建模式产生乱码。地名复用 `LoadTownMapEntry` 和现存地图名称数据。
- 原名称右对齐例程保留 `DE` 字符串地址，`FixStrLength_Gen1`、`GetStrLength_Gen1` 使用跨 Bank `callfar`；SAVE 不清空 START 仍在使用的全局 DFS 字形缓存。
- 原版徽章与图鉴数值采用 **数字＋中文单位** 独立绘制；用户先前截图中「枚」「只」的右边缘相对地点／玩家名仍有轻微视觉偏差。**这一像素级对齐问题未作为本次 C 补丁已修复项目，不应标为全部右对齐验收通过。**
- 不增加 SRAM/存档字段，不修改原有黑屏回城机制，不增加常磐森林飞行权限，不覆盖野外 SELECT 自行车快捷键。
- 项目要求 AI 不自行编译/链接 ROM；源码补丁校验及静态检查不能替代维护者的红版 `make red` 与手机/模拟器测试。

## 后续维护规则

1. 每项独立开发与实测；当前正式 HEAD 只有在维护者真实 Git Commit 并提供新导出后才更新。
2. 同步标记：用户真实验收范围、尚未覆盖的红版 DMG/CGB 显示、Bank/SRAM/WRAM 是否变化以及发生过的失败实验。
