- **用户验收与剩余工作**：用户确认七项核心操作和中文屋顶收尾均无问题；这不代表全部特殊点逐点落点录像或所有红蓝、DMG/CGB 组合已覆盖。百货屋顶光标与玉虹市位置重合属明确接受的暂缓视觉事项；维护者需本地构建最终 ROM、MAP 并归档。14 个原有静态入口实际 2 PASS、12 FAIL（以旧版本守卫为主），本轮定向 Fly 源码检查 PASS；清理增量不改用户已验证的游戏行为。

### ROM-1.30 地名牌技术边界

- **保留原 ROM-1.28 的范围边界**：FIX 只修正 SAVE / Continue 地点行，不纳入此前独立开发的 `ROM-1.27D`“数字＋单位完整右对齐”实验补丁；不能把 D 的效果冒称为本次修正版内容。
- SAVE / Continue 信息框保留原版横向位置与 **13 格内容宽度**。ROM-1.28FIX 的第一行不再绘制「当前位置」固定标签，只显示地图名；ROM-1.30 继续按完整字符边界截断，并将上限由 6 格放宽到 8 格以容纳「无人发电厂」，不拆分 DFS 双字节汉字，也不改变字号。
- ROM-1.28 曾将地点行 `DFSStaticize` 到 `vChars2 $40-$5F`；修正版移除这一步，因为该图块区间在户外仍可作为场景图块使用。地点名改为直接使用现有 DFS 绘制，减少固定字形占用并避免 DMG/CGB 场景图块冲突。地名仍复用 `LoadTownMapEntry` 和现存地图名称数据。
- 原名称右对齐例程保留 `DE` 字符串地址，`FixStrLength_Gen1`、`GetStrLength_Gen1` 使用跨 Bank `callfar`；SAVE 不清空 START 仍在使用的全局 DFS 字形缓存。
- 原版徽章与图鉴数值采用 **数字＋中文单位** 独立绘制；用户先前截图中「枚」「只」的右边缘相对地点／玩家名仍有轻微视觉偏差。**这一像素级对齐问题未作为本次 C 补丁已修复项目，不应标为全部右对齐验收通过。**
- 不增加 SRAM/存档字段，不修改原有黑屏回城机制，不增加常磐森林飞行权限，不覆盖野外 SELECT 自行车快捷键。
- 项目要求 AI 不自行编译/链接 ROM；源码补丁校验及静态检查不能替代维护者的红版 `make red` 与手机/模拟器测试。

- ROM-1.30 地名牌仅在 CGB 运行；使用 Window BG `$9c00`、VRAM Bank 1、Palette 5 和 Bank `$3D` 资源。START/对白/战斗以及完整 Warp 接管 Window/地图前会先回收地名牌。
- 连续刷新采用 CHS 专用双名字缓冲：新名字先写入非活动的 36 个 8×8 tile，再在屏蔽中断的全新 VBlank 中原子切换两行 tile ID；显示总时长保持 120 帧。
- New Game / Continue 首次进入与 Fly 共用短延迟；ROM-1.30 正式范围支持 36 个城镇/道路标签及常青森林、月见山、岩山隧道、地鼠洞穴、无人发电厂 5 个物理地标。完整 Warp 离开前先清牌、目标图按 Fly 延迟显示；普通地图连接继续即时刷新。
- **用户反馈基本无问题：RPP #217 西尔佛公司 1F～11F。** 11 层独立地名牌，电梯保持 neutral；非 Fly warp pad 可在进入动画前预备标签。该反馈不替代所有平台的详尽测试矩阵。
