# CHS_Mod DMG 60 FPS 移植验收记录（FPS-1.4）

## 本轮已完成

- 以已提交 `ROM-1.3` 的 CHS 工程为基线，移植独立的 DMG 野外 60 FPS。
- 野外循环按帧运行、玩家逐帧移动；NPC、脚本、飞行及跳台动作做节奏补偿。
- 未启用 CGB 双倍速或新增的 CGB 颜色处理；保留汉化工程原有兼容路径。
- 当前工作区先使用 `FPS-1.4A` 测试标识；本轮只清理为 `FPS-1.4`，不修改已测试的功能指令。

## 验证情况

- **用户实测**：用户反馈 DMG 60 FPS 没有问题，要求正式清理提交。此反馈不代表已测试全部场景。
- **交付静态检查**：增量与全量补丁基线对应、可正向应用和反向撤销；两份补丁应用后源码及文件权限一致。
- **尚待验证**：本轮没有重新编译 ROM；红、蓝正式版 MAP 和 ROM0 余量以用户本地生成结果为准。

## 后续独立研究

- CGB 颜色异常与双倍 CPU 独立排查，不在 `FPS-1.4` 中叠加或启用。
- 优先检查 ROM 头硬件模式、SGB 与 CGB 配色路径、背景/精灵调色板初始化及 Bank 切换。
