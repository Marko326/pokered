## 先说明：参考 Crystal Audio 与 CHS 音频架构不同

- RPP `#051～#056`、`#060` 的 `crysaudio/engine.asm` 以 **Music On/Off、BGM Volume、静音时解析、NR50/NR51 路由**为功能/修复链，其中部分 Bug 是该功能链引出的后续问题。
- CHS 当前源码包含 `src/audio/engine_1.asm`、`src/home/audio.asm`，**不存在同名的 `crysaudio/engine.asm` 以及参考的 Music Off / 0～10 独立 BGM 音量流程**。音频引擎不同，不应因为参考补丁标题写着“死机”或“爆音”，就认定 CHS 有该缺陷。
- 但是**不能反过来推断 CHS 所有声音问题都不存在**：若实际出现治疗结束噪声、战斗招式音高异常，要沿 CHS 自己的播放链复现/审查；它们不是本批能直接 cherry-pick 的 RPP 修复。
- `#051` 与 `#053` 是**可选新增功能**，因此标为“需评估”；`#052/#054/#055/#056/#060` 是**依赖该实现的修复**，标为“当前不适用”。不要将这些状态混为一谈。

## 状态口径

- **已实现**：CHS 代码或统一验收记录能支持同等结果；实现方法可以不同。
- **部分实现**：CHS 只有部分目标已覆盖，未证明参考的完整效果/宏改造全部完成。
- **需评估**：新增功能、对话与交互偏好、其他 Bank 空间调整或构建工具优化，是否实施要看 CHS 的需求。
- **当前不适用**：参考依赖的系统或功能前置在 CHS 不存在，**不是待修 Bug**；若同类现象出现，应另开 CHS 复现单。
- **依赖暂缓**：不能独立摘取后续补丁，需要和上游改动共同设计。
- **待核验**：参考确认有 Bug，但 CHS 是否有**相同触发链**还缺证据；此类不应自动标“未修复”。本批无必须马上归入此类的确认项。
